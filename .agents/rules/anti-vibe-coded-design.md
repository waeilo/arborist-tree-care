# 🛡️ Strict Anti-Vibe-Coded Design System Rules

Every UI component built in this workspace MUST follow these strict, human-handcrafted design mandates. **Zero exceptions.**

---

## 🚫 1. STRICTLY FORBIDDEN (AI Vibe-Coded Clichés)

1. **NO Universal Icon Overload:** Do NOT stuff standard stock icons (Lucide, FontAwesome) on every single button, card, or heading. Icons must be rare, bespoke, or custom SVG illustrations.
2. **NO Generic Box-in-Box Layouts:** Do NOT wrap every element in identical glowing border cards, rounded outline boxes, or repetitive Bento grids. Let elements float naturally with whitespace.
3. **NO Stock AI Gradients & Colors:** BAN generic purple-on-dark, neon violet glows, or stock blue button gradients. Use curated, organic HSL color palettes with deep contrast.
4. **NO Uniform Sans-Serif Monotony:** Never use a single generic font everywhere. Always pair distinct editorial typography (e.g., Playfair Display / Serif for headlines & numbers, Outfit/Inter for metadata).
5. **NO Static Message Bubbles:** Never use generic static chat bubble icons for AI features. AI widgets must be dynamic, visual, and interactive.
6. **NO Reflexive Text Encasing & Box Trapping:** Never instinctively wrap short messages, tooltips, or hints in pill boxes, outline cards, or bordered badge containers. Let text breathe as pure, consumable editorial typography with natural contrast and whitespace—demonstrating actions through pure motion rather than trapped boxes.

---

## 💎 2. MANDATORY HUMAN CRAFTSMANSHIP (Bespoke & Dynamic)

1. **Proximity-Aware Dynamic Interactions:**
   * Interactive elements MUST react to cursor/finger proximity. 
   * *Example (AI Assistant):* When the cursor gets near the AI widget, it dynamically expands, winks, shifts lighting, or morphs to invite interaction—never remaining a static icon.
2. **Custom Visual Components:**
   * Build bespoke Canvas/SVG widgets (like our 3D visual rotating Spin-to-Win wheel with real physics) instead of standard text buttons or stock icons.
3. **Invisible Architecture & Editorial Whitespace:**
   * Let content and high-res visuals take center stage. Use floating borderless layouts, editorial magazine compositions, and tactile depth.
4. **Fluid Kinetic Physics:**
   * Micro-interactions, drag behaviors, and hover states must feature organic easing (`cubic-bezier(0.15, 0.85, 0.35, 1)`), smooth inertia, and dynamic scale feedback.
