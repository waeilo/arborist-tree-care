# 🌲 ARBORIST Care & Removal Services — Web & AI Diagnostic Platform

> **Ultra-luxury, high-conversion Tree Care, Surgery & Preservation platform** crafted with artisanal typography, fluid kinetic micro-interactions, responsive multi-step booking, real-time before/after project sliders, and conversational AI tree diagnostic capabilities.

---

## 🌟 Highlights & Architecture

### 1. 🍃 Client Experience & High-Conversion Booking
- **Fluid Multi-Step Appraisal Dispatch:**
  - **Step 1 (Services):** Visual service selector with hazard tags (Tree Removal, Trimming, Pruning, Stump Grinding, Emergency Storm Response).
  - **Step 2 (Location Engine):** Verified 50-county autocomplete registry covering **Ireland** (Dublin, Cork, Galway, Limerick, Waterford) and **Australia** (Sydney, Melbourne, Brisbane, Perth, Adelaide) with wavy gradient shimmer loading and GPS pinpointing.
  - **Step 3 (Slot Coordination):** Time window selection grouped by regional crew dispatch routes.
  - **Step 4 (Specimen Details):** Photo upload and access/gate notes.
  - **Step 5 (Confirmation):** Review, instant SMS confirmation link, and calendar dispatch.
- **Interactive Before & After Project Sliders:**
  - Smooth drag/touch split slider comparing authentic project transformations across private estates and residential parks.

### 2. 🎙️ AI Live Voice & Chat Tree Assistant
- **Aborist AI Call Audio Screen:**
  - Organic 3D fluid botanical sphere reacting with smooth ambient pulses.
  - Live conversation transcript with acoustic specimen diagnostics and ISA arborist analysis.
  - Uncluttered phone experience with centered transcript telemetry and feathered edges.

### 3. 🏢 Full Owner Administrative Operations Hub (`/owner`)
- **Dashboard Overview:** KPI stats (revenue, active crews, pending hazard appraisals, safety score).
- **Dispatch Calendar:** Route-optimized service appointments and crew calendar view.
- **Customer CRM:** Appointment logs, tree hazard photos, specimen notes, and contact channels.
- **Settings & AI Configuration:** Custom dispatch radiuses, emergency rates, and business rules.

## 🚀 Instant Cloud Deployment

This repository is pre-configured for zero-config, 1-click cloud deployments.

### Option A: Deploy to Vercel (Recommended)
1. Fork or push this repository to your GitHub account (`waeilo/arborist-tree-care`).
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Select this repository and click **Deploy**.
4. Vercel automatically reads `vercel.json` and deploys your site to an `https://*.vercel.app` URL instantly.

### Option B: Deploy to Netlify
1. Go to [Netlify Dashboard](https://app.netlify.com/start).
2. Connect your GitHub repository.
3. Build command: *(leave empty)*.
4. Publish directory: `.` (root).
5. Netlify reads `netlify.toml` and deploys with immutable asset caching.

### Option C: Deploy to Cloudflare Pages
1. Go to **Workers & Pages** in Cloudflare Dashboard.
2. Connect to Git, select this repository, and deploy with framework preset **None (Static HTML)**.

### Option D: GitHub Pages
1. In repository settings, navigate to **Pages**.
2. Source: **Deploy from a branch**.
3. Branch: `main` / Folder: `/ (root)`.
4. Click **Save**.

## 💻 Local Development & Preview

Run locally using any static file server:

```bash
# Install local preview server (optional)
npm install

# Start local server on port 3000
npm start
```

Or with Python:
```bash
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
